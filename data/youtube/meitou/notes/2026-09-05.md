# 2026-09-05

## 为何软件股集体大涨？AI新风口浮出水面！哪些公司能做实反转？
[视频链接](https://www.youtube.com/watch?v=01s3YdYUCcU)

### 核心判断
- 本轮财报季软件是表现最好的板块（IGV 一个月涨近 30%），原因是两个 AI 趋势首次在财报里得到验证：软件公司帮客户降低 token 成本；软件公司转型为 AI Agent 的基础设施。
- 软件和大模型不是谁取代谁，而是“你中有我、我中有你”的合作关系：垂直、需要强上下文、对 token 成本敏感的任务由软件主导调用模型；跨系统、对成本不敏感的任务由大模型主导调用软件。
- 大部分大模型长期是商品属性，没有溢价权，只有少数顶尖模型能建立生态、掌握入口。
- AI 对软件“促进和威胁同时存在”，软件板块将进入强分化：掌握企业级任务入口、有完整上下文和执行权限、工作流足够深的公司受益；依赖表层使用体验做壁垒的 C 端软件更容易被 AI 威胁。
- 市场在用“现在的软件 vs 未来的 AI”衡量颠覆风险，他认为应比较“未来的软件 vs 未来的 AI”，所以 AI 颠覆风险被高估、软件应用 AI 撬动的增量被低估。

### 背景：算力瓶颈与软件的位置
- 他三个月前的观点：AI 算力瓶颈是会长期持续的问题，不会因为某几家半导体公司或大模型进步就彻底解决；系统性降低 token 成本能创造巨大商业价值，软件股是最能做到这点的群体之一，也是被忽略的机会。
- 软件公司在 AI 时代的优势不在技术，而在定义需求和流程的能力：Agent 从零开始跑任务很耗 token，流程一旦固定，同样任务的 token 消耗会大幅降低。
- 半年前软件因 AI Agent 颠覆担忧遭“无差别扫射”，是美股表现最差的板块之一。

### 趋势一：软件公司降低 token 成本
- 从“把自己打包成 MCP 给大模型用”转向“开发自己的 Agent，在自己的环境里给客户用”。
- 关键是上下文：例子是 Atlassian（Jira、Confluence、Bitbucket），在它自己的 Agent 里问“项目为什么延期”，因为已有全部足迹和任务关联，不用像外部大模型那样大海捞针。
  - 管理层披露：Agent 使用 Teamwork Graph 做上下文 grounding 时，回答准确率最高提高 44%，token 消耗最高减少 48%。财报后股价大涨 35%。
  - HubSpot、MongoDB、Workday、ServiceNow 本季也展现出类似能力。
- 模型中立（model-neutral platform）：软件公司把自己建成多模型平台，按任务调用最合适的模型。
  - 最早是微软 Copilot 在做，自称融合了 1.1 万个模型（含 DeepSeek 等开源模型）。
  - Workday 的 Contract Intelligence 已嵌入多个模型组合；Snowflake 推出 Cortex AI Gateway，按质量、速度、成本偏好自动选模型。
  - 更重要的不是模型个数，而是软件公司长期深耕垂直领域、比用户更了解工作流，所以更能帮用户省 token。

### 趋势二：软件公司成为 AI Agent 的基础设施
- Salesforce CEO：未来会主动接入 Claude 和 ChatGPT 平台，不再占用用户的工作界面。Shopify：不管交易由人还是 Agent 完成，都希望运行在最底层。Snowflake：希望成为企业 Agent 的控制中枢。
- 看似向大模型低头，但这几家财报后都暴涨；Salesforce 暴涨的核心原因是与 Anthropic 的深度合作。
- 以 ServiceNow 为例：通过 Action Fabric 和 MCP 把数据、权限、工作流开放给外部 Agent，按 Assist 单位计费（Agent 每执行一次工作流消耗一个 Assist，任务越复杂消耗越多）；席位数没减少，又多了 Assist 收入；管理层称本季 50% 的净新增业务采用非席位定价。
- Salesforce、Snowflake、Workday 思路和结果基本相同：席位不变的前提下增加新收入，用户对软件的依赖反而加深。
- 原因：数据背后的工作流、权限、商业逻辑、责任机制和安全仍由软件公司掌控，大模型没有能力也没有意愿接管这些垂直流程，最好的办法是合作。

### 对投资的含义
- 降低 token 成本是企业客户对软件的新增需求；成为 Agent 基础设施相当于新增了一类用户——从按人收席位费到按 Agent 收用量费。人的增量有限，Agent 的增量才刚起步。
- 他点名的典型受益公司：ServiceNow、Salesforce、Snowflake，以及“Vira”（转写不清，前文举例的是 Atlassian / Jira）。他强调这不是荐股。

### 提及的公司
- SNOW：他在付费服务中唯一维持 Strong Buy 评级的软件公司；半年前股价一度腰斩，最近一季距低点已翻三倍。此前担忧：AI 威胁、企业预算有限且增量主要来自老客户、Databricks 竞争。他认为担忧被高估——新 CEO（技术出身，做过 AI 创业）快速应对；分析师低估了增长，因为企业决策者愿意为“带来新可能性”的工具付费，不只看能否增收，数据分析需求没有天花板，AI 数据分析的 token 消耗在指数增长。
- TEAM：Teamwork Graph 让 Agent 准确率最高 +44%、token 消耗最高 −48%，财报后大涨 35%。
- CRM：与 Anthropic 深度合作是财报后暴涨的核心原因；将主动接入 Claude 和 ChatGPT。
- NOW：Action Fabric + MCP 开放给外部 Agent，Assist 计费；50% 净新增业务采用非席位定价。
- SHOP：希望无论人还是 Agent 交易都运行在最底层；财报后暴涨。
- WDAY：Contract Intelligence 嵌入多模型；席位不变下增加新收入。
- HUBS、MDB：本季展现了上下文优势。
- MSFT：Copilot 最早做模型中立，自称融合 1.1 万个模型。
- GOOGL：下期付费视频专题讲 TPU，称其已成为谷歌第二增长曲线（“小英伟达”），可能是左右谷歌股价最关键的变量，但影响并非完全积极，甚至可能拖累谷歌。
