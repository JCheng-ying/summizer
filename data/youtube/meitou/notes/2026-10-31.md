# 2026-10-31

## 个人Agent横空出世！新一轮军备竞赛即将展开！AI又要变天了？
[视频链接](https://www.youtube.com/watch?v=U6DV0MzMBJs)

### 核心判断
- 个人 Agent 长期一定能走通，市场空间与 B 端 Agent 大致相当；但短期有三个困难：太烧钱、需要信任、平台不一定放行。
- 基本只有巨头能做成；目前 Meta 优势最大、最可能最快跑出来，谷歌最可能后来居上；OpenAI、Anthropic、Grok、苹果不太看好。
- 对应用层公司短期没有太多可期待：处于烧钱期，现金流会很难看。投行预估个人 Agent 2027 年底开始变现（他同意），倒推股价爆发最快 2027 年年中。
- 在此之前的机会：2027 年是个人 Agent 竞争年和新一轮军备竞赛，最先受益的是基础层（算力、半导体），与过去两年 B 端竞赛的剧本相同。

### 个人 Agent 现状
- Meta 的 Muse：36 天美国下载量 900 万（ChatGPT 达到同样数字用了 110 天）；他认为是除 ChatGPT 外最成功的消费端 AI 产品。
- OpenAI 9 月底发布 Dots；Anthropic 上周推出 Claude Duet（名称转写不清）；谷歌面向消费者的版本预计四季度推出。
- ChatGPT 当个人 Agent 用的三个痛点：免费版只是聊天机器人、没有执行能力；卡在密码 / 信用卡这一步；不会主动找你。
- Muse 的解法：
  - 执行：每个用户配一台云端虚拟机（带浏览器，24 小时在线，关掉 App 也在后台干活），把原本只能在工作电脑上用的 Agent 搬到手机上；执行力不见得比 Codex 强，但改变了使用场景。之前门槛是要专门买一台电脑（如年初很火的“小龙虾”）。
  - 安全：账号密码单独保管，干活的 AI 自己也看不到；付款用一次性卡号。
  - 主动性：会看邮箱、日历，主动提醒和建议（他自己的例子：Uber 一个月免费会员到期当天 Muse 提醒他取消），降低了使用门槛。
- 定位区分：ChatGPT 像大号搜索；B 端 Agent 是完成工作的工具；个人 Agent 像真正的私人助理。

### 市场空间
- 旅游、订酒店交给 Agent，OTA 生意可能被替代；整个数字广告都有机会转移到 Agent 上。
- 大摩：未来可通过 Agent 数字化的消费支出约 32 万亿美元，一半多是电商和旅游；按 3% 抽成算，接近 1 万亿美元收入的潜在市场。

### 为什么长期能成
- 对“只是退订、比价等一次性需求”的质疑，他承认短期存在，但长期不是问题。
- 逻辑：人天生想偷懒，社会一直把不想干的事外包（洗衣机、洗碗机、外卖、网购）；现在付账单、管密码、比价、预约这些琐事也能交出去。私人助理以前只有有钱人请得起，现在免费。
- Muse 不是最终形态，会快速迭代；类比智能手机早期“能打电话发短信就行”的质疑。

### 三个困难
- 烧钱：免费个人 Agent 运行成本约为免费 ChatGPT 的 10 倍（执行任务 token 消耗远高于问答；全天在线、每人一台虚拟机、安全设置都要花钱）。
  - 大摩：每位 Muse 用户每月成本 3–130 美元；免费额度用满每月 128 美元，一年 1000 多美元。
  - OpenAI 把 Dots 捆绑在每月 100 美元的 Pro 套餐，免费和每月 20 美元的用户都用不了，原因是成本太高。
  - 扎克伯格在财报会上提到成本是限制 Muse 扩张的重要因素。
- 信任：美国调查显示只有 3% 的人愿意让 AI 不经确认就交易，4% 愿意让它独立完成购买。
- 平台放行：亚马逊封了 Muse，摩根大通不让此类 Agent 访问客户账户。他认为亚马逊名义上是安全，实际更担心广告。几乎所有个人 Agent 都依赖谷歌 Gmail 和日历，这些连接理论上随时可能被切断。长期平台大概率会逐步放开，但拉扯会让扩张不够快。

### 赢家需要的能力
- 有别的业务补贴烧钱，并尽快找到变现方式（广告或交易抽成）。
- 多年积累的用户信任。
- 足够话语权让商家、银行放行，或自己掌握大量用户数据。
- 分发渠道和用户基础（Muse 扩张比 ChatGPT 快，Meta 分发功不可没）。
- 捕捉用户意图的产品力，而不只是模型能力。
- 结论：基本只有巨头能做；有特色的小公司（如 Instinct，名称转写不清）难长期撑下去，大概率被收购。参赛者：Meta、谷歌、苹果、OpenAI、Anthropic，再加 Grok。

### 提及的公司
- META：目前领先。广告收入可观、算力行业最多、创始人要多少资源给多少；Muse 基础功能完全免费、token 给得大方；30 多亿 C 端用户，最会对消费者变现；社交业务本身靠抓用户意图；C 端产品做得顺手（像 WhatsApp 聊天）。社交数据尚未接入 Muse，未来会是差异化核心。短板是信任——Oppenheimer 调查“愿意信任谁保管密码”：谷歌 30%、苹果 23%、ChatGPT 16%、Meta 8%（最后）；越往后碰到的钱越多，问题越突出，需继续观察。Meta 已在融资。
- GOOG：最可能后来居上。信任度最高、广告生意不比 Meta 小、有 Gmail / 地图 / YouTube / Android 的分发和数据。市场顾虑是与搜索广告左右互搏，他认为这是短期最大问题，但长期谷歌无路可退、最有紧迫感（别人是锦上添花，谷歌是生死存亡）。真正的问题：内部产品太多、抢资源、难统一战略，没有扎克伯格那样敢孤注一掷的创始人，决心待验证。只要管理层下决心打通 Gmail、日历、安卓，追上来不难，他保持积极。最新季报后股价大跌 12%：搜索业务史无前例下跌，谷歌云史无前例大涨（详细分析在付费的美投Pro）。
- AAPL：握有 iPhone 入口、软硬结合、独有私人数据、最强隐私口碑；致命问题是没有自己的模型（用谷歌 Gemini），软件层慢一拍；入口也没想象中重要（按锁屏键叫 Siri 和打开 Muse 差别不大）。前景 mixed，更可能成为收“入口费”的角色，类似今天浏览器和搜索的关系。
- OpenAI / Anthropic（未上市）：模型最强、OpenAI C 端用户最多，但两家最缺钱，靠外部融资，收入主要来自 B 端，广告、电商等 C 端变现能力很弱；B 端竞争已够烧，再做免费 C 端不一定扛得住。Muse 证明个人 Agent 上模型没那么重要（Meta 模型不算最强）。今年早些时候 B 端 Agent 成功变现才带动了两家估值。
- Grok：情况与 OpenAI、Anthropic 差不多，位置更尴尬。
- AMZN：封了 Muse（见上）。
- JPM：不让此类 Agent 访问客户账户。

### 他的建议或布局思路
- 不要指望个人 Agent 短期给上述公司带来爆发性增长；要看的信号是变现。
- 2027 年变现前的机会在基础层（算力、半导体）。
- 他强调这个判断很主观、变量多，要走一步看一步。
