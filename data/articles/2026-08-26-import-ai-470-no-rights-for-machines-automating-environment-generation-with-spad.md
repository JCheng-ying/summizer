# Import AI 470: No rights for machines; automating environment generation with SPADE; and building better GPU kernels with Hawkeye
https://importai.substack.com/p/import-ai-470-no-rights-for-machines

这期 Import AI 的几条技术新闻放在一起,讲的是 AI 研发自动化正在往两个此前需要大量人工投入的环节渗透——生成训练用的环境本身,以及针对具体硬件优化底层代码,而与此同时,AI 加速科学进步这件事本身也呈现出明显的不均衡分布。

先说一项衡量"加速"本身的研究。METR 的一份分析研究了 AI 在网络安全、数学、AI 研究这三个领域里到底在多大程度上加速了进展,结论是网络安全领域加速非常明显——2026 年多个项目(cURL、OpenSSL、Firefox、微软)和汇总漏洞数据库(美国 NVD、OSV)报告的漏洞发现速率相比 2025 年大幅提升;数学研究有小幅加速但更难衡量——arXiv 投稿量在部分领域不到 12 个月翻倍,一些知名难题(Smale 列表里的 Jacobian 猜想、Green 列表第 44 题)被解决,但现在判断这个趋势能否持续还为时过早;AI 研究本身的算法优化则几乎没有可测量的加速——在 CIFAR-10、Hutter 压缩、Gurobi 混合整数规划等七个重要问题领域里,只有 nanoGPT 和 CIFAR-10 两个领域能看到 LLM 带来的贡献,而且增长速率远低于网络安全和数学领域。文章的判断是,加速效应似乎是某种"相变"式地出现在特定技能上(比如 2025 年的日常编程、2026 年的网络安全),关键问题是这种相变会不会在科学技术的其他领域也复现。

第二条是关于训练环境自动生成的进展。多所高校(华盛顿大学、斯坦福、东北大学、卡内基梅隆、麻省理工、新加坡国立、首尔国立、史蒂文斯理工、芝加哥大学)的研究者构建了 SPADE(自适应合成可执行环境中的自我对弈),让一个 LLM 在两个角色间交替——"环境设计者"负责把长程训练环境写成可执行代码,"推理智能体"负责在这些环境里学习行动,奖励信号来自"推理智能体"在有无"特权提示"(环境设计者附带的部分解题线索)两种情况下表现的差距。团队在 Qwen3 系列的三个规模(4B、8B、30B-A3B)上测试,30B 版本效果最好,在游戏类环境上比基线提升 8.1 分,比最强的固定环境基线高 5.3 分,工具使用类环境上也有类似提升。文章指出这本质上是一种巧妙的合成数据生成技术,让研究者用手头已有的强模型去生成更多样化的训练环境,反过来训练同一个模型或其他模型——理论上可以在不同前沿模型之间来回切换来增加环境生成的多样性,这会显著降低构建大规模、多样化训练数据集的成本,不过作者也承认这种方法不能让模型的能力大幅超越用于生成环境的基础模型本身的想象力上限。

第三条是关于 GPU 底层代码优化的进展。哈佛、斯坦福、Together AI、加州理工的研究者构建了 Hawkeye,一个帮助 agent 学习为特定 GPU 硬件写高度优化底层代码(kernel)的框架,目标是回答"怎么用最少的专家干预让编程 agent 具备硬件感知能力"。Hawkeye 的核心贡献是一套"最小化但足够全面的单元测试分类体系"——每个单元测试把一个人类编写的解决方案 kernel 和验证优化效果的性能指标打包在一起,附带简短的使用说明,让 agent 既能当作语法示例阅读,也能直接调用或拼接组合成更大的 kernel。文章给出的结果:在 NVIDIA Ampere、Hopper、Blackwell 和 AMD MI350 这几代硬件、跨 BF16/FP8/NVFP4/MXFP4 多种精度上,Hawkeye 在已有成熟工作负载上能匹配或超过 cuBLAS、cuDNN、FlashAttention 这些专家调优的厂商库;在 torch.compile 无法融合的新型注意力变体上,相比 Flash Linear Attention 库里专家编写的 Triton kernel,Hawkeye 实现了 18.9 倍的几何平均加速。文章的判断是,只需要一点点人类精心整理的知识(打包成 Hawkeye 这类工具),AI 系统就能匹配甚至超越高度优化的人类专家工作成果。

文章还提到两篇观点性文章,呈现了 AI 研究者群体内部关于"AI 意识/AI 权利"这个问题的分歧——一篇是 Julian Togelius 公开了他 2025 年经历的一次"信仰危机",担忧人类才华和天赋在超级智能面前变得不再重要;另一篇是研究者 Taylor Belrose 明确反对给 AI 系统赋予权利,认为 AI 系统建立在计算基质上、不满足意识所需的若干生物学特性(异步神经元放电、模糊化学信号、计算与记忆混杂等),不应该被当作有意识的实体对待。这两篇文章本身不构成投资信号,但反映了 AI 研究者群体内部对超级智能社会影响的焦虑正在从技术讨论扩展到哲学讨论。

个人看法:SPADE 和 Hawkeye 这两项工作合在一起看,呈现的是同一个大方向在两个不同环节的具体落地——AI 研发自动化正在啃下此前必须靠人类专家投入的两块硬骨头:构建多样化训练环境(SPADE)和针对具体硬件写高度优化代码(Hawkeye),这两件事此前都需要大量专家人力,现在都能用"用少量人类精心设计的知识去引导 AI 自我改进"这个共同范式来自动化。用"先找瓶颈"的方法看,**AI 板块**里这两项工作分别对应两个不同层面的瓶颈:SPADE 解决的是"高质量多样化训练数据/环境从哪来"这个数据瓶颈,Hawkeye 解决的是"新硬件/新精度格式怎么快速获得优化支持"这个硬件适配瓶颈——后者尤其值得关注,因为它直接关系到算力生态的竞争格局:如果 AMD MI350、NVIDIA Blackwell 这类新硬件能借助 Hawkeye 这类工具快速获得接近专家水准的 kernel 优化,会显著缩短新硬件从发布到被开发者充分利用之间的时间差,这对硬件厂商打破 CUDA 生态的先发优势是一个间接利好信号,值得作为算力生态多元化进展的一个观察指标持续跟踪。METR 那篇研究提醒的则是一个更谨慎的判断:AI 对科学进步的加速效应目前还高度不均衡,只在少数领域(网络安全)出现了明确的"相变式"加速,这意味着"AI 正在全面加速科研"这类笼统表述目前证据并不充分,值得对各个细分领域分别评估,而不是一概而论。
