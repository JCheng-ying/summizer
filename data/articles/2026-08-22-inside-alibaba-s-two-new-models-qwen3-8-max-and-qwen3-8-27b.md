# Inside Alibaba's Two New Models, Qwen3.8-Max and Qwen3.8-27B
https://www.deeplearning.ai/the-batch/qwen3-8-max-lands-with-a-bang/

这篇文章讲的是阿里巴巴发布的两款新模型,但真正值得记录的是一次策略转向——阿里第一次把自己最顶级的 Max 系列模型开放了权重,而这个决定本身,是在被 Moonshot AI 的 Kimi K3 抢占"最大最强开源模型"位置之后做出的竞争回应。

文章指出,阿里 8 月 2 日先发布了 Qwen3.8-Max,一款 2.4 万亿参数的视觉语言模型,面向长程编程和知识工作任务;一周之内又发布了 Qwen3.8-Max 和更小的 Qwen3.8-27B 的权重——这是阿里第一次给 Max 级别的模型开放权重(此前的 Max 系列只通过 API 和 Qwen Chat 应用提供,只有更小的模型如 Qwen3.6-27B 才开源权重)。但文章特别指出这次开放是有保留的:公开权重版本的 Qwen3.8-Max 只支持文本输入输出,不支持视觉能力,也不支持完整的百万 token 上下文窗口——也就是说,开发者能自己部署的版本,能力上是打了折扣的。架构上,Qwen3.8-Max 是混合专家(MoE)架构搭配混合注意力机制,总参数 2.4 万亿,每个 token 激活约 950 亿参数,延续了 Qwen3.5 的技术路线,把标准注意力层和"门控 Delta 网络层"(一种更节省内存的注意力替代方案)结合起来;从预训练阶段开始就联合处理文本和图像,而不是给已训练好的语言模型外挂一个视觉编码器,这个设计让模型能在规划、执行、验证过程中直接检查渲染输出的正确性。阿里还配套推出了 QwenWork,一个专门运行这个模型的 agentic 工作框架,训练时在任务长度(单任务、多任务、跨多天任务)、工作空间复杂度(单文件、多文件、层级文件夹)、以及使用的工具框架这三个维度上做了强化学习扩展。

性能上,文章列出的数字:Qwen3.8-Max 在 Artificial Analysis 智能指数上拿到 58 分,比上一代 Qwen3.7-Max(47 分)跳升 11 分,整体排名第五、开源模型里排名第二,超过 Claude Opus 4.8(57 分)和 Muse Spark 1.2(57 分),但落后于 Kimi K3(60 分);在 τ³-Banking 银行客服模拟测试上拿到 51.3%,是所有测试模型里的最高分;在 GDPval-AA v2 上拿到 1739 Elo,仅次于 Claude Opus 5 和 Claude Fable 5。文章也指出了代价:这次性能提升是靠生成更多 token 换来的,尽管单 token 价格不高,但完成同样任务消耗的 token 数更多,推高了单任务实际成本。至于开放权重的许可条款,文章特别提到 Qwen3.8-Max 的自定义许可类似 MIT 协议,但月活超过 1 亿或月收入超过 2000 万美元的使用场景需要署名,基于该模型构建的、年收入超过 5000 万美元的模型即服务或编程助手还需要单独申请许可;相比之下 Qwen3.8-27B 是完整能力版本,采用标准的 Apache 2.0 协议,没有这些附加条款。

文章还交代了这次策略转变的产业背景:自 2025 年 1 月 Max 系列诞生以来,阿里一直只通过 API 和 Qwen Chat 提供最强模型,中国国内的开源权重竞争一直是 Moonshot AI 和 Z.ai 在你追我赶——Kimi K3 发布几天后,阿里就在上海世界人工智能大会上预告了 Qwen3.8-Max,8 月 2 日通过 API 开放,Z.ai 随后在 8 月 14 日发布了 GLM-5.3(Artificial Analysis 智能指数平均分 60)跟进。文章的判断是,虽然大多数团队根本没有能力自己部署一个 2.4 万亿参数的模型,但开放权重的真正价值会通过第三方托管服务商之间的价格竞争、以及 Qwen3.8-27B 这类蒸馏版本体现出来;开放权重也让开发者可以"货比三家"选择更好的隐私条款,因为任何服务商都可以托管这些权重,包括那些承诺不保留用户数据的服务商。

个人看法:这篇文章值得和之前的[MiniMax H3](2026-08-14-minimaxs-state-of-the-art-video-model-is-only-minimally-open.md)、以及今天读到的[Grok 4.6](2026-08-22-grok-4-6-rivals-claude-opus-5-and-gpt-5-6-sol-at-a-lower-price.md)放在一起看——这三篇文章合在一起,勾勒出当前大模型竞争里三种不同的"开放"策略:MiniMax 是"开源"标签下留了大量限制的做法,阿里这次是"顶级模型开权重但阉割能力"的折中方案,而 SpaceXAI/Grok 走的是完全闭源加收购数据源的路径。这说明"开源"这个词在当前这轮竞争里已经不是一个二元判断,而是一条连续的光谱,每家公司都在根据自己的竞争位置选择站在光谱的哪个点上——阿里选择在 Kimi K3 抢占"最大开源模型"位置后跟进开权重,本身就是一个防御性的竞争回应,而不是单纯的技术理念选择。用"先找瓶颈"的方法看,**AI 板块**里这次事件真正指向的瓶颈是"能自己部署 2.4 万亿参数模型的基础设施能力"——文章自己也承认"少数团队能自己托管这个规模的模型",这意味着开放权重的真正受益者不是终端开发者,而是能够提供大规模模型托管服务的第三方云服务商和推理优化公司,它们会在阿里、Moonshot AI、Z.ai 这几家开源模型之间的价格竞争中获得议价空间。这篇文章本身没有具体的公司间合作关系可以往图谱里加,更多是模型能力和开源策略层面的信号更新,值得后续关注的是 Qwen3.8-27B 这类蒸馏版本能不能在消费级硬件上跑出实用的体验,那会是"开源模型能不能真正下沉到本地部署"这个 edge AI 板块 相关问题的一个具体验证案例。
