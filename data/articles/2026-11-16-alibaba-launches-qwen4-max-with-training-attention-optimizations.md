# Alibaba launches Qwen4-Max with training, attention optimizations
https://siliconangle.com/2026/11/16/alibaba-launches-qwen4-max-with-training-attention-optimizations/

阿里这次发布 Qwen4-Max,真正值得注意的不是"又一个更强的旗舰模型",而是它几乎所有改进都指向同一个方向:用架构去换算力。在前沿模型竞争里,美国实验室的主线一直是堆更多 GPU,而中国实验室在先进芯片受限的前提下,越来越多地把创新放在"同样的效果少花多少计算"上。如果这种效率路线持续奏效,那么模型能力和算力投入之间的关系会被削弱,这对整个 AI 基础设施的需求逻辑是一个值得认真对待的变量。

文章指出,Qwen4-Max 的主干网络有 2.4 万亿参数,但任何时刻只激活 710 亿,这是典型的稀疏混合专家(MoE)设计;另外还有 3280 亿所谓的 N-gram 参数,作用类似缓存,把经常重复出现的计算结果存起来,不必每次从头计算。这个思路相当于把一部分"记忆"从需要实时计算的权重里剥离出来,变成查表,本质上是在用存储换计算。

在训练层面,文章介绍了它对残差连接的改造。残差连接是几乎所有大模型都有的"捷径",让信号和梯度可以绕过部分层直接传递,从而让深层网络更容易稳定训练。文章说,过去的实现通常是一条通道,而 Qwen4-Max 用了四条通道,并且加了"门控"来调节梯度的流动,目的是减少训练过程中的误差,从而降低成本、提升输出质量。在注意力层面有两个定制:第一是 Gated DeltaNet,一种降低长提示处理所需硬件量的机制(这类线性注意力的好处是计算量不随上下文长度平方增长);第二是 QSA,跳过回答提示时用不到的数据片段,进一步降低基础设施成本。

效果上,文章称在阿里自己包含知识工作任务的内部基准上,Qwen4-Max 得分高于上一代 Qwen3.8-Max,同时完成任务所用 token 最多少了 35%;在 Terminal-Bench 4.0 编程任务上,token 节省扩大到 49%。需要注意的是,前者是阿里的内部基准,没有独立复现。模型目前通过阿里云提供,阿里计划之后开源一批基于同样技术的较小模型,同时开源 Qwen-Live-Delivery-Plugin,让模型在长时程任务中先快速给出初稿,再迭代改进,用户可以中途给反馈。

个人看法:这篇和之前写过的[阿里 Qwen3.8-Max 与 Qwen3.8-27B](2026-08-22-inside-alibaba-s-two-new-models-qwen3-8-max-and-qwen3-8-27b.md)、以及[DeepSeek 新旗舰只比 Flash 模型略强](2026-09-01-deepseek-s-new-flagship-only-slightly-outperforms-flash-model-open-source-harnes.md)可以放在一条线索里看。中国头部实验室的共同特点是:在算力受限的情况下,创新集中在稀疏激活、线性注意力、缓存和 token 效率上。再结合之前写过的[出口禁令下的英伟达芯片支撑了中国最强模型](2026-11-13-export-banned-nvidia-chips-are-behind-china-s-most-powerful-ai-models-uh-oh-jens.md)那篇,能看出一个矛盾:一方面管制在收紧,另一方面效率路线让"少量算力也能做出接近前沿的模型"变得更可行,这会削弱出口管制的实际效果。

用"先找瓶颈"的思路看,这篇文章里的瓶颈其实很清楚:不是模型能力,而是推理成本,尤其是 agent 和长时程任务带来的 token 消耗。token 少用 35%-49% 意味着同样的任务单位成本大幅下降,而 agent 场景的经济可行性恰恰卡在这里。因此受益的层次会是:第一层是 AI板块 里的应用和 agent 层,推理成本下降直接扩大可落地的任务范围,尤其是编程 agent;第二层是云平台本身,阿里云可以用更低的单位成本服务更多调用,模型效率直接变成云业务毛利;第三层是 edge AI板块,阿里承诺开源基于同技术的小模型,稀疏激活加线性注意力的组合天然适合内存和功耗受限的端侧设备,这对手机、PC 和端侧芯片厂商(比如高通、联发科这类 SoC 供应商)是潜在利好。至于 GPU 和数据中心这一层,我认为短期仍是确定性受益方,因为效率提升往往会刺激更多使用量,但需要警惕的是,如果效率路线被西方实验室大规模采纳,"每单位能力需要多少 GPU"的预期可能被重新定价。

目前这些都还是阿里自己公布的数字,值得跟踪的是两个信号:一是开源小模型发布后,第三方基准能否复现类似的 token 节省;二是 Gated DeltaNet 这类线性注意力会不会被更多实验室采用,成为下一代模型的默认配置。
