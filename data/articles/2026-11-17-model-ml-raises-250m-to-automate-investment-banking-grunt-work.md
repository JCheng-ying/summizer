# Model ML raises $250M to automate investment banking grunt work
https://techcrunch.com/2026/11/17/model-ml-raises-250m-to-automate-investment-banking-grunt-work/

这篇融资新闻背后的命题是:垂直行业 AI agent 的竞争,正在从"谁的模型最强"变成"谁能用最便宜的模型把一个行业的具体工作流吃下来"。如果一家专做投行助理工作的公司可以在开源模型上做到前沿模型约 2% 的成本,那么金融这类高价值白领行业的 AI 化,真正的价值未必落在模型层,而是落在懂流程、接得进客户系统的应用层。

文章指出,总部在伦敦的 Model ML 完成 2.5 亿美元 B 轮融资,估值 15 亿美元,由 General Atlantic 和早期投资方 QED Investors 联合领投;距离它宣布 7500 万美元 A 轮仅一年。公司成立三年,由 Chaz 和 Arnie Englander 兄弟创办,两人此前联合创办过 P2P 租赁平台 Fat Llama,后者 2022 年以 4150 万美元被瑞典同行 Hygglo 收购。Model ML 做的是替代初级投行分析师和咨询顾问的那部分工作:搭财务模型、做 pitch deck、写尽调报告。它的 agent 接入客户自己的系统、数据和 Excel、PowerPoint 等工具,公司称 agent 能理解一笔交易的完整上下文,当出现影响分析的新进展时,会自动更新模型和演示文稿。

文章还给了两个参照系。第一是同赛道对手,Hebbia 和 Rogo 也在自动化投行和咨询的重复性工作,其中 Rogo 4 月以 20 亿美元估值融了 1.6 亿美元;第二是模型厂商本身,Anthropic 和 OpenAI 都已经为金融从业者做了工具。Model ML 的回应是它跑在开源模型上,成本大约只有前沿模型的 2%,速度还更快——这个数字来自公司自己的说法,文章没有给出独立验证。

个人看法:投行初级分析师的工作其实是一个很好的 agent 落地样本,因为它可以拆成三层:第一是数据层,从 CapIQ、公司财报、内部数据室里取数;第二是推理层,把数据装进三表模型、DCF、可比公司分析;第三是呈现层,按银行的模板改 Excel 和 PPT,而且每次交易条款一变,三层都要连锁更新。真正耗人力的往往是第三层和"连锁更新"这一步,这恰好是 Model ML 宣称解决的问题。这和今天早些时候写的 [决策模型那篇](2026-11-17-as-decision-model-use-skyrockets-is-customization-the-next-frontier.md) 是同一条线索:企业在把大量流程节点从昂贵的前沿模型上挪走,用更便宜的开源模型或者专用模型去做,前沿模型只留给真正需要深度推理的环节。也和 [Ramp 数据显示 AI 支出停滞](2026-11-08-ramp-data-shows-ai-spending-stalling-just-as-anthropic-nears-its-ipo.md) 那篇的判断一致——用量在涨,但花在前沿模型上的钱不一定跟着涨。

投资角度,先找瓶颈:金融行业 AI 化的瓶颈不在模型能力,一个会做 DCF 的模型现在并不稀缺,瓶颈在于第一,能不能安全地接入银行内部的数据和权限体系;第二,能不能把输出稳定地做成银行认可的格式;第三,单位成本能不能低到值得替换一个初级分析师的工时。Model ML 的估值押的是第一和第三点。受益的层次会是:第一层仍然是算力和推理基础设施,开源模型跑得便宜,不代表推理量变少,反而是成本下降之后调用量会放大,GPU、云平台以及提供开源模型托管推理的服务商都是量的受益方;第二层是开源模型的提供方,Meta 的 Llama、Mistral、Qwen、DeepSeek 这一类模型被越来越多垂直应用当作底座,虽然开源本身不直接收费,但对 Mistral 这类靠企业部署和托管收费的公司是正面的;第三层才是 Model ML、Hebbia、Rogo 这类垂直应用,它们的护城河是行业流程和客户数据接入,而不是模型。相对承压的是 Anthropic、OpenAI 在金融垂直场景的直接收入,如果 2% 成本的说法站得住,前沿模型在这类"高频、格式固定"的任务上议价能力会被削弱。这篇整体挂 AI 板块,和机器人、能源等其他板块没有直接关系。

现在一家三年的公司估值 15 亿美元,一年内从 A 轮到 B 轮估值大幅抬升,这说明资本仍然愿意为垂直 agent 付溢价,但这条赛道已经有至少三家资金充裕的玩家,同时模型厂商也在下场。值得跟踪的是 Model ML 是否公布具体的大型银行客户和续约情况,以及 Anthropic、OpenAI 的金融工具是否开始用更低价的模型档位来回应这种"2% 成本"的竞争。
