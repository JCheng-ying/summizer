# MIT Researchers Build VISTA, an Agent Harness That Keeps Images in Memory for Faster Retrieval
https://www.deeplearning.ai/the-batch/context-engineering-for-images/

这篇文章讨论的是 Agent 的记忆问题从文本延伸到图像:与其让模型更大,不如改进模型外面的"脚手架"(harness),把看过的东西完整存下来并允许回头翻查。这再一次说明 Agent 能力的提升有相当一部分来自上下文管理,而不只是模型本身。

文章指出,MIT 的研究团队发布了 VISTA,一个以 MIT 许可证开源的 Agent 框架。传统做法是把游戏或交互环境里的每一帧图像编码成 embedding 放进上下文,上下文满了就删掉。这有两个问题:第一,embedding 是有损压缩,可能丢失关键信息;第二,一旦删除,模型就再也拿不到那些信息。VISTA 的做法是把所有帧完整存进持久记忆,并给 Agent 一个检索工具,可以调出任意历史帧、放大任意局部。每一步 Agent 在四个动作里选择:读写笔记、检索历史帧、检索历史动作及结果、执行动作。笔记分两种,一种是跨关卡可复用的环境知识(比如棕色方块和黑色背景的区别),一种是当前关卡的状态(比如角色有了什么能力、之前在什么条件下失败)。

结果方面,VISTA 搭配 Claude Opus 5.0 在 ARC-AGI-3 交互式视觉推理谜题上拿到满分 100 的相对人类动作效率(RHAE),即所有谜题都比第一次玩的人类用更少动作完成,文章称比首次接触的人类少用 57.4% 的动作;搭配 GPT-5.6 Sol 拿到 99,而去掉存帧能力后降到 70。在 GameWorld 上,VISTA + GPT-5.6 Sol 平均完成 63.3% 的任务,首次玩的人类是 55.3%,原生框架只有 40%。

个人看法:这和之前写过的 Stroop Test 那篇的结论一致:Transformer 本身不擅长长期保持目标,所以真正的进步来自外面加的 Memory、Planner 这些管理层。VISTA 证明了这个思路在视觉上同样成立,而且很便宜,不需要重新训练模型。对机器人来说这尤其重要,因为机器人每秒都在产生画面,一个能"回放并放大"历史画面的 Agent,本质上就是给机器人加了视觉长期记忆。先找瓶颈:Agent 落地卡在长任务中的信息遗失。受益的层次会是:第一层是存储和推理算力,保存所有帧、反复检索放大意味着更多存储和更多推理调用;第二层是 Agent 框架和记忆层软件,这类开源 harness 会被快速吸收进主流 Agent 平台;第三层是做具身 Agent 的机器人公司。我会把它挂在 AI 板块和机器人板块,但要说明这只是游戏环境里的结果,离真实机器人还有距离。值得关注的是有没有团队把这种帧记忆用到真机长任务上。
