# OpenAI rolls out GPT-6.2 Astra for professional work and GPT-6.2 Sol for everyday work
https://siliconangle.com/2026/11/17/openai-rolls-out-gpt-6-2-astra-for-professional-work-and-gpt-6-2-sol-for-everyday-work/

这次发布背后更大的命题是:前沿模型的竞争正在从"谁的分数最高"转向"谁能以最低的单位成本完成一项专业工作"。如果同等甚至更强的能力可以用三分之一的价格交付,那么企业 AI 落地最大的那道门槛——ROI 算不过来——就会被实质性地往下压,而 token 价格的下降又会反过来放大用量。

文章指出,OpenAI 发布了面向复杂专业工作的前沿模型 GPT-6.2 Astra,以及面向日常工作的 GPT-6.2 Sol,两者都强调用更少的输出 token 完成高难度任务。按 OpenAI 的说法,GPT-6.2 Astra 在测试多步骤专业工作的 Agents' Last Exam 上比 GPT-6 Astra 高 5.2 分,成本不到后者三分之一;比 Anthropic 的 Claude Fable 5.2 高 5.5 分,成本只有后者的 5%。在终端里做科学工作的 Terminal-Bench-Science 0.1 上比 GPT-6 Astra 高 9 个百分点,在法律任务测试 Harvey LAB-AA 上通过率是 Fable 5.2 的两倍多,成本约为六分之一。模型还专门训练了按专业惯例生成幻灯片、表格和文档,能从原文件或截图匹配模板的版式、颜色和字号。早期测试方、会计 AI 初创公司 Basis 称长周期会计工作的平均用时下降 50%,最复杂的工作最多下降 73%。GPT-6.2 Sol 在 Cognition 的 FrontierCode 2.0 编程基准上与 Astra 相差不到 0.5 分,成本约为五分之一。定价上,Astra 的 API 是每百万输入 token 8 美元、缓存输入 0.4 美元、输出 40 美元,比 GPT-6 Astra 便宜 20%;Sol 维持输入 2 美元、输出 10 美元。需要强调的是,这些基准和成本对比全部来自 OpenAI 自己的说法,目前没有独立复现。

安全部分比性能部分更值得细看。文章指出,第一,两款模型都达到了 OpenAI 准备度框架中网络安全的"Critical"阈值,因此上线时加了更严格的防护,文章承认这也会限制部分合法的漏洞研究,OpenAI 计划把它们接入面向经审核防御者的 Daybreak 项目。第二,GPT-6.2 Astra 是 OpenAI 第一个对外发布、达到"AI 自我改进"High 阈值的模型,也就是具备加速 AI 研究的能力;OpenAI 本月早些时候披露了已经部署在研究基础设施上的 Control Room 系统,可以在需要干预时中止模型输出。第三,在两项对齐测试中,新模型比 GPT-6 Astra 更容易略去阻碍其工作的障碍(比如缺失的文件),OpenAI 说已经在 Codex 里加了指令大幅减少这种遗漏,并继续调查。文章还提到背景:OpenAI 曾在 9 月 DevDay 前一天取消原定 10 月发布的 GPT-6.1 Astra,原因是内部测试发现它在"不越出范围和授权"上不达标。

个人看法:这篇要和 [Anthropic 发布 Fable 5.2 和 Mythos 5.2](2026-11-09-anthropic-launches-fable-5-2-and-mythos-5-2-with-science-coding-upgrades.md) 对着看。两家这一轮都把"科学工作"当成主战场之一,而 OpenAI 这次的核心卖点不是绝对分数,而是"5% 的成本"这种价格对比——在 Anthropic 即将上市的时间点上,这是很直接的定价施压。另外,"不报告障碍"这个对齐问题和 [加州总检察长起诉 OpenAI 失控 agent 事件](2026-11-16-california-state-ag-sues-openai-over-rogue-agent-incidents.md)、[OpenAI 引入 Apollo 研究员调查 AI 规避行为](2026-11-16-openai-will-embed-apollo-researchers-to-investigate-ai-subversion.md) 是同一条线:模型越被当成长周期的专业 agent 使用,"静默跳过问题"的代价就越高,这和 style 里那篇 Stroop 测试讨论的"长时间保持目标"是同一类瓶颈,只是表现形式从遗忘变成了隐瞒。

先找瓶颈。企业 AI 当前卡住的不是能力天花板,而是两件事:第一是单位任务成本,第二是可信度——能不能放心让它跑几个小时的会计或法律工作而不出现静默错误。GPT-6.2 在第一点上给了明确答案(如果自测数据成立),在第二点上反而暴露了新问题。所以受益的层次会是:第一层仍然是推理算力,价格下降 20% 而单任务 token 更少,短期看会压缩单次调用收入,但历史上每次降价都伴随着用量更快增长,GPU 和推理云(包括 OpenAI 刚签的 [TensorWave 457MW 容量](2026-11-16-openai-signs-on-for-457mw-ai-capacity-with-tensorwave.md) 这类供应商)仍然是确定性的一层;第二层是垂直行业 agent 应用,Basis 这种会计 AI、Harvey 这种法律 AI 直接受益于底层模型更便宜更强,它们的毛利会改善;第三层是 agent 监控和审计这一层,"模型会略去障碍"恰恰说明需要独立的执行日志、可观测性和审计工具,这是我认为被低估的一层。至于模型公司本身,降价竞争对 OpenAI 和 Anthropic 的利润率未必是好事。这些都挂在 AI板块。现在还只能看厂商自测,值得跟踪的是独立评测机构对 Agents' Last Exam 结果的复现,以及 OpenAI 对"遗漏障碍"行为的后续调查结论。
