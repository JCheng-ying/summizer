# Minimax's State-of-the-Art Video Model Is Only Minimally Open: Minimax H3's weights are free, but carry unusual restrictions
https://www.deeplearning.ai/the-batch/minimaxs-state-of-the-art-video-model-is-only-minimally-open/

这篇文章讨论的是"开源"这个词在 AI 模型领域正在被怎样重新定义——权重免费下载,不等于真正开放。

文章指出,MiniMax 发布了视频生成模型 H3,支持文本、图片、音频、视频等多种输入组合生成视频,在 Artificial Analysis 的视频编辑榜单排名第一,文生视频和图生视频也基本处于并列第一梯队。但这个模型的授权协议里藏着一个不寻常的条款:美国、英国、欧盟和韩国的用户,必须先向 MiniMax 单独提交申请、说明用途"合法、负责且不侵犯任何权利",才能获得和世界其他地区用户一样的使用条件。技术架构上,H3 由三个模块组成——负责理解和整合多种输入媒介的推理模块 H3-Context-IR、负责生成 768p 视频的基础模型、以及把 768p 升级到原生 2K 分辨率的 H3-Regenerate-2K——但只有基础模型免费开放下载,其余两个模块保持闭源。授权条款还要求商业用户必须在产品里显著标注模型名称,禁止用 H3 的输出去蒸馏训练别的模型,并且明确排除用于伤害未成年人、干扰选举等场景。

文章把 H3 放进了当前视频生成模型的竞争格局里对比:人类偏好评分(ELO)上,H3 和谷歌的 Gemini Omni Flash、字节跳动的 Dreamina Seedance 2.0 处在同一梯队;曾经坚持开源路线的 Black Forest Labs,最新的 FLUX 3 已经改成了纯闭源、只通过 API 提供,可能会加入这个"第一梯队"的竞争;字节的 Dreamina Seedance 2.5 也还没有经过独立测试。

个人看法:这篇文章和几天前 Microchip/Hailo 那类"边缘 AI 芯片收购整合"的信号完全不是一个维度,但和"开源模型到底意味着什么"这条线索是相通的——之前 Thinking Machines 发布 Inkling 时,专门花了大篇幅讲外部安全测试和分阶段发布方法论,是在"真开源、但负责任地开源"这个方向上做文章;MiniMax H3 则是反过来,用地域性的申请门槛,实质上把"开源"变成了"对大多数国家开源、对少数发达经济体半开源"。文章原文直接批评这种按国家/地区限制权重使用的做法"违背了开源的本意"——开源的核心意义是任何人都能下载、理解、使用一个模型,而不是变成一种可以被区别对待的准入门槛。这提示 **AI 板块** 里"开源"这个标签本身正在变得需要仔细拆解来看,不能看到"权重免费"就默认等同于"完全开放",实际的商业化条款、地域限制、模块级别的开放程度,都需要逐条核实。

个人看法:投资角度上,视频生成这个细分赛道目前呈现出至少四家(MiniMax、Google、字节跳动、Black Forest Labs)同时角逐第一梯队的格局,且都不是简单的"谁的模型更好看"就能分胜负——MiniMax 选择的差异化路径是"真实数据训练 + 内置提示词优化流水线"(原文提到他们刻意回避使用合成数据,因为高质量视频文本对本身就稀缺),这类"数据策略差异"可能比单纯的模型架构差异更能决定长期竞争力。值得持续跟踪的信号是:MiniMax 这类地域限制条款会不会被其他厂商效仿成为行业惯例,以及视频生成模型的商业化路径最终会走向"卖 API 调用量"还是"卖授权给下游内容生产工具"这两种不同的变现模式。
