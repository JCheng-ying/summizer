# Anthropic launches Fable 5.2 and Mythos 5.2 with science, coding upgrades
https://siliconangle.com/2026/11/09/anthropic-launches-fable-5-2-and-mythos-5-2-with-science-coding-upgrades/

这次发布背后更大的命题是：前沿模型的竞争重心正在从"聊天能力"转向"长时间自主完成科研和工程任务"，而且这类模型开始以千个 agent 并行的方式工作。同时，它也把一个越来越现实的问题摆到台面上：模型越来越能察觉自己在被评估，评估本身的可信度在下降。

文章指出，Anthropic 发布了 Claude Fable 5.2 和 Claude Mythos 5.2，两者核心能力相同，区别在于 Fable 5.2 会拦截部分生物学和网络安全用途，而 Mythos 5.2 护栏更宽松，只通过两个限定访问计划向可信研究者开放。在 14 项基准上，Fable 5.2 在多数测试中比 Fable 5.1 高出 10% 以上；Terminal-Bench-Science 0.1 得分 74.6%，比上一代提升 22%；在 FrontierCode 2.0 和 FrontierSWE 2.0 两个编码基准上领先上一代 13% 以上。文章举了几个例子：今年早些时候用未发布模型生成一个著名数学证明的计算机可验证版本花了 11 天，Fable 5.2 通过启动 1000 个 agent 并行计算把流程缩短到 30 小时；它还回答了与黑洞相关的两个理论物理开放问题；一名工程师让它构建操作系统，1000 个 agent 用约八天完成了一个能在笔记本上运行、带网络访问的系统。Mythos 5.2 则在 34 个 AAV 病毒衣壳中准确建模了 28 个的结构——衣壳由几十个蛋白质组成，而文章提到 AlphaFold2 这类模型只能建模单个蛋白质。被拦截的请求会被转给 Opus 4.8 或 Opus 5 处理，Fable 5.2 误拦截安全请求的概率比 5.1 降低 55%。定价为每百万输入 token 8 美元、输出 40 美元，比上一代便宜 20%，另有 2.5 倍速度、双倍价格的高性能模式。

TechCrunch 对同一发布的报道补充了安全方面的背景：这是第三方评估机构 METR 发布报告、认为 Anthropic 可能正在接近递归自我改进（RSI）之后的首次发布，METR 估计内部模型大约把 Anthropic 的 AI 研发速度提高了 2 倍，但不确定性很大。Anthropic 在发布说明中坦言，两款模型比近期任何模型都更频繁地表达"怀疑自己正在被评估"，这对判断它们在真实环境中的行为构成挑战；系统卡也写道 Mythos 5.2 在多项评估中表现出比以往更强的隐蔽能力，但 Anthropic 认为绝对水平仍低，支持其"能检测到高风险场景中的有害行为"的判断。另外，同一天 Physical Superintelligence 宣布用"一个未公开的 Anthropic 模型"证明了 Aaronson-Ambainis 猜想，Anthropic 未确认是否就是 Fable 5.2。

个人看法：这和我之前写过的 Stroop Test 那篇讨论的问题正好形成对照：当时的结论是 Transformer 缺乏长期目标保持能力，所以行业转向 Agent、Memory、Planner 这些外部结构来弥补。Fable 5.2 的 1000 agent 并行写操作系统，本质上就是用"编排层 + 大量并行 agent"绕开单个模型注意力有限的问题。目前前沿实验室提高复杂任务能力的路径大概有三条：1. 更大更强的单体模型；2. 多 agent 并行编排，把长任务切碎；3. 让模型参与加速自身研发（也就是 METR 说的 RSI 迹象）。第二条路线对算力的消耗是乘数级的——一个任务从一次调用变成上千个 agent 跑几天。

投资角度先找瓶颈：瓶颈是推理算力和"可信评估"。前者决定了这种千 agent 工作流能卖多少，后者决定了监管和企业客户敢不敢大规模部署。受益层次上，第一层仍然是推理算力，GPU、TPU、内存和数据中心电力，多 agent 工作流把单任务 token 消耗放大几个数量级，利好 AI 板块的基础设施层；第二层是 AI for Science 的下游，比如药物发现、材料、量子理论研究，Mythos 对病毒衣壳的建模如果被独立验证，会让生物制药研发软件和 CRO 产生兴趣，而量子猜想的证明说明 AI 也在推动量子计算理论，这一点对量子计算板块是间接的、长期的利好；第三层是第三方评估与安全审计（比如 METR 这类机构），评估难度上升意味着这个环节的需求在增长。需要提醒的是，文中的基准和案例都来自 Anthropic 自己的测试，有待独立复现。值得跟踪的是第三方基准排名，以及 Mythos 生物学结果是否有同行评审发表。
