# Tokenomics: Putting a price on intelligence
https://www.datacenterdynamics.com/en/analysis/tokenomics-putting-a-price-on-intelligence/

这篇 DCD 的分析文章讨论的是 AI 时代云计算的计价单位正在改变:从"按实例、按小时"转向"按 token"。这背后的命题是,谁来承担算力利用率波动的风险——按 token 卖,风险在云厂商;按 GPU 小时或长期合约卖,风险在客户。这个选择决定了不同类型云厂商的商业模式和抗风险能力。

文章指出,Uptime Institute 的云经济学家 Owen Rogers 认为 token 是最公平的计价方式,因为客户只为实际使用付费,而不用为闲置的 GPU 和软件买单。输出 token 比输入 token 贵,因为解码阶段消耗更多昂贵的显存操作。文章举例说,Google 在 2026 年 5 月称每月处理约 3.2 千万亿个 token。具体怎么定价,欧洲云厂商 Scaleway 的 CEO Damien Lucas 给出了拆解:先算底层基础设施成本(比如在自有数据中心用 Nvidia B300 集群跑 Mistral 模型的硬件和电费),得出每小时能产出多少 token;再加上付给模型方的授权费和带宽等成本;最后确定可接受的利用率,100% 等于卖光了,不可接受,最佳点在 60% 到 70%。他还提到,新一代 GPU 理论上每 token 成本更低,但现实是推理需求被最大的前沿模型拉动,这些模型只能跑在最新 GPU 上,所以新模型上新卡、小模型上旧卡,而且新模型授权更贵、每次请求要更多 token。Vast Data 的 Jason Hammons 则认为提高 GPU 利用率的关键在数据访问的并行化。Nutanix 首席 AI 官 Debojyoti Dutta 用"买房、长租、Airbnb"类比三种模式:自建、租 GPU、按 token 付费,稳定负载的客户租 GPU,新进入者需要按 token 的弹性,而提供弹性的云厂商就要承担预留多少冗余的风险。文章称主要云厂商今年资本开支都在 2,000 亿美元量级,数据中心建设与 IT 硬件的支出比例大约是 40:60。所以云厂商更希望客户签大额长期合约。neocloud 代表 Lambda 的联合创始人兼 CTO Stephen Balaban 说,Lambda 一年半前放弃了基于开源模型的 token API,现在只按 GPU 小时卖,因为专有模型进步更快,Lambda 定位为给最大的前沿模型供电的"算力公用事业",像电力公司卖千瓦时一样卖 GPU 小时,做出这个调整后增长明显加快。

个人看法:我觉得这篇文章把 AI 云的商业模式分成了清楚的三层:第一层是模型公司(OpenAI、Anthropic、Mistral),按 token 卖,赚的是模型溢价;第二层是超大规模云厂商,两种模式都做,用长期合约兜底、用 token 服务吃弹性溢价;第三层是 neocloud,像 Lambda 这样只卖 GPU 小时,本质是"算力公用事业",赚的是稳定但薄的租金。这里的瓶颈其实是利用率风险:Scaleway 说 60%-70% 才是最佳点,意味着三到四成的算力是为波动预留的,而 GPU 又贵又折旧快。谁能解决利用率问题,谁就是真正受益的那一层,包括提升 GPU 利用率的存储和数据层(Vast Data 这类)、调度和编排软件,以及能锁定长期合约的大客户关系。对 AI 板块来说,这篇文章的信号是偏正面的:token 处理量巨大、资本开支还在增加,而且"最新模型只能跑在最新 GPU 上"意味着硬件更新周期不会因为旧卡还能用而放缓,对 Nvidia 和 AMD 的新品需求是支撑。但也要看到风险:neocloud 靠长期合约维持,如果前沿实验室的需求放缓,这些合约的续约就是最大的不确定性。值得跟踪的是 neocloud 的合约续约率,以及按 token 定价的价格战会不会进一步压低模型公司的毛利。
