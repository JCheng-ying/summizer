# Q.ANT Demonstrates Hybrid Photonic-GPU System for Language Models
https://thequantuminsider.com/2026/11/17/q-ant-demonstrates-hybrid-photonic-gpu-system-for-language-models/

先说明利益相关:本文依据的是 Q.ANT 在 SC26 上发布的新闻稿,"更精简的模型、更少参数和数据、显著降低能耗和运营成本"等说法均为公司自我宣称,稿中没有给出任何具体的速度、能效或模型精度数字,应按未经独立验证处理。

这件事背后的命题是:光子计算如果想进入 AI 数据中心,靠的可能不是"用光把 GPU 正在做的事情做得更快",而是"让模型去用光天然擅长的数学"。前者是和 GPU 正面竞争,后者则是改写算法本身,让光子芯片成为 GPU 旁边的一个协处理器。这次演示的意义就在于它第一次把后一条路落到了语言模型上。

文章指出,Q.ANT 推出了 NPU Gen 2+,在 2025 年发布的 Gen 2(主打矩阵乘法和非线性运算)基础上,加入了一个片上光学元件,可以在一次运算里直接完成离散傅里叶变换(DFT)。DFT 是信号处理、图像处理、仿真和数据分析里的基础运算,在数字硬件上处理大数据量时要花大量时间和能耗,而光通过干涉和传播的物理过程可以"一次过"完成。文章提出,这相当于把可用指令集从经典计算的加法和乘法往外扩了一步,让模型可以用更少的参数和数据达到同样的表达能力。

最关键的演示是:在 SC26 上,Q.ANT 把 NPU Gen 2+ 和一块 AMD GPU 组成混合系统运行一个大语言模型,用光学完成的傅里叶运算替换掉其中一个计算量很大的注意力层。这里需要说清楚技术上的含义:标准 Transformer 的自注意力要计算每个 token 与其他所有 token 之间的相关性,计算量随序列长度平方增长;而学术界早就有一类"用傅里叶变换做 token 混合"的思路(典型如 Google 的 FNet),用 FFT 替代注意力矩阵,把复杂度降到 N log N,代价是表达能力有一定损失。Q.ANT 做的,本质上是把这类 Fourier 注意力层放到光上去算。软件负责人 Utz Bacher 的话也印证了这一点:与其优化现有代码,不如探索用这些原生运算去解决问题的不同算法,Fourier 注意力层是早期例子。

文章还交代了商业化路径:第一,硬件仍然通过 PCIe 插进标准机架服务器,不改变数据中心形态;第二,9 月开源的 SDK(C 和 Python API、基于 CPU 的仿真环境)正在扩展支持 Gen 2+ 的 DFT 能力,开发者不用碰硬件就能先试 Fourier 算法;第三,Q.ANT 计划在 2027 年下半年提供 Gen 2 与 Gen 2+ 组合的商用系统,后续还要在同一块芯片上组合更多光学功能。

个人看法:这和一周前 [Q.ANT 与 IONOS 的光子计算试点](2026-11-09-q-ant-and-ionos-launch-pilot-for-photonic-computing.md) 是同一条线索的下一步。那篇我提过光子路线的三个瓶颈是精度、软件栈兼容和光电转换开销,这次 Q.ANT 的应对很清楚:不和 GPU 抢通用矩阵乘法,而是找一个"GPU 算起来贵、光算起来天然便宜"的运算(DFT),再说服开发者改模型结构去用它。这和昨天 [Qwen4-Max 在训练和注意力上做优化](2026-11-16-alibaba-launches-qwen4-max-with-training-attention-optimizations.md) 指向同一个事实:注意力层是当下大模型推理成本最集中的地方,所有人都在想办法绕开它的平方复杂度。目前来看有三种方式:1. 在数字硬件上改算法,比如稀疏注意力、线性注意力、KV cache 压缩,这条路完全在 GPU 生态内部完成;2. 在数字硬件上做专用加速,比如推理 ASIC 针对注意力做定制;3. 换物理介质,像 Q.ANT 这样把某类运算交给光。第三种的门槛最高,因为它要求模型本身用 Fourier 层替代标准注意力,而这类模型目前在主流前沿模型里并不常见,质量是否能对齐还没有公开数据。

投资角度,先找瓶颈:瓶颈是推理阶段注意力的算力和能耗。真正解决它的那一层,短期内仍然是 GPU 和数字侧的算法优化,所以 AI 板块里算力层的确定性没有被改变,反而这次演示本身就是"光子作为 GPU 协处理器",AMD 作为合作的 GPU 方出现,说明光子路线在可预见的时间里是给 GPU 做加法而不是取代它。第二层是光子集成电路的制造链,Q.ANT 用的薄膜铌酸锂和数据中心光互联属于同一类材料工艺,这一层不管光计算能不能跑出来都在受益。第三层才是 Q.ANT 这类光子计算公司本身,它是未上市的早期公司,目前只是 AI 板块里一个值得跟踪的变量。另外文章出自量子计算媒体,但光子计算和光量子计算是两回事,这件事不支撑量子计算板块的判断。现在离 2027 年下半年的商用系统还早,值得关注的信号是:Q.ANT 或第三方能否公布这个混合系统跑的模型规模、与标准注意力相比的精度损失,以及每 token 能耗的具体数字。
