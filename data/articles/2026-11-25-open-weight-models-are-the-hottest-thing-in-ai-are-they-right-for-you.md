# Open-weight models are the hottest thing in AI. Are they right for you?
https://siliconangle.com/2026/11/25/open-weight-models-are-the-hottest-thing-in-ai-are-they-right-for-you/

这篇文章讨论的是企业 AI 架构正在发生的一次结构性转变:从"所有请求都走一家前沿模型的 API"转向"按任务难度把工作分层,分配给不同大小、不同来源的模型"。如果这个转变成立,AI 的价值不会被前沿实验室独占,而会更多地流向模型路由、推理托管、评估工具链,以及企业自己机房里的算力。

文章指出,开源权重模型(公开参数、可下载、可微调,但不一定公开训练数据和代码,许可证也各不相同)正在快速占领流量。Vercel 的 AI Gateway 月报显示,开源权重模型在其观测到的 token 流量中的占比从去年 12 月的 7% 升到今年 8 月的 56%,8 月 OpenRouter 按 token 量排名的前十个模型里有八个是开源权重。资本层面也有两笔大交易:成立三年的 OpenRouter 8 月以 75 亿美元卖给 Stripe,英伟达 9 月以近 130 亿美元收购托管超过 300 万个模型的 Hugging Face。能力差距也在收窄,文章引用 Mozilla 9 月的报告,领先开源权重模型和闭源前沿模型的差距约为四个月,两年前是 18 个月;斯坦福 HAI 认为月之暗面 2.8 万亿参数的 Kimi K3 和阿里 2.4 万亿参数的 Qwen3.8-Max 在编程基准上接近闭源模型;Tenzai 的一个 agent 用 Z.ai 的 GLM 5.2 登上 HackerOne 排行榜第一,单位算力的发现数比之前基于闭源模型的基线多 30%。

文章认为成本是最主要的驱动力。从问答式生成转向多步 agent 工作流之后,推理成本飙升,Gartner 预测到 2028 年每个 agent 工作流的推理成本会增长五倍以上。几个企业案例给出了量级:据 The Information,AT&T 已把 40% 的 AI 工作负载转到开源模型,计划提高到 70%,通过路由器把代码摘要这类任务分给更便宜的模型,AI 运营成本降低 56%,质量只下降 2%;Pinterest 称离开前沿模型后 AI 运营成本节省超过 90%;Uber 今年头四个月就烧完了全年 AI 预算,此后通过把更多负载转到开源权重模型,把模型请求量减少三分之一、单次会话成本降低一半以上。除了成本,文章还列了三个同样重要的理由:第一是合规,数据、权重和提示词都不出组织边界,更容易满足 HIPAA、GDPR 和欧盟 AI 法案;第二是透明,开源权重可以拿到 log-probability 和置信度分数,用真实结果去校准;第三是性能,多步 agent 里 50 个串行步骤每步 500 毫秒的 API 延迟就会累积成 25 秒,把模型放在数据库旁边或边缘容器里能减少路由跳数。Hyperscience 自称用蒸馏得到的小模型成本降低最多 97%、推理快四倍,并保留 95% 以上的指定任务性能,这是厂商自述数字。

文章同样花了很大篇幅讲隐藏成本,这部分比"开源更便宜"更有价值。第一,开源权重不等于开源软件,许可证差异很大,比如 Liquid AI 的模型只对年收入低于 1000 万美元的组织免费商用,上游训练数据的分发权和法务审计成本会转移给企业。第二,token 只是成本的一部分,一次 JSON 格式错误触发的自动重试可能消耗数百万 token,人工返工可能抹掉几个月的节省。第三,自建并不一定便宜,Cast AI 去年春天报告它监测的数千个集群平均 GPU 利用率只有 5%,Gartner 分析师的说法是开源模型在高利用率下便宜得多,而间歇性负载用前沿 API 更划算,因为不用为闲置算力付费。第四,换模型通常解决不了问题,DevRev 估计 agent 从干净的测试工具搬到真实企业环境,准确率会下降 18% 到 19%,而升级模型带来的提升不到 1%,真正的瓶颈是数据集成和接口复杂度。文章的结论是,企业应该把任务分层:检索、嵌入、文档分类这类低层任务交给小型开源模型,自主推理和重构复杂遗留系统交给商业前沿模型。

个人看法:这篇和 [Token sticker shock 那篇 Dell 访谈](2026-11-17-token-sticker-shock-pushes-enterprises-from-frontier-labs-toward-open-weight-ai-.md) 是同一条线,而且结尾还引用了同一位 Dell 的 Brad Maltz。当时我的判断是混合模式会是大多数企业的最终形态,这篇用 AT&T"40% 到 70%"的路线和"按任务分层"的结论基本印证了这一点。它也和 [Tokenomics: putting a price on intelligence](2026-11-21-tokenomics-putting-a-price-on-intelligence.md) 呼应——token 成本管理正在从技术问题变成财务管理问题。Hugging Face 被英伟达收购这件事,可以对照之前 [Import AI 471 讨论 Hugging Face 的那篇](2026-09-01-import-ai-471-why-hugging-face-worries-me-space-mining-five-eyes-on-ai.md),以及 [Import AI 476 关于中国开源权重模型的部分](2026-11-01-import-ai-476-creativity-and-rsi-worse-than-china-open-weight-models-ai-goes-to-.md):文中点名的 Kimi K3、Qwen3.8-Max、GLM 5.2 都是中国模型,说明企业开源权重流量里有相当一部分跑在中国模型上,这对美国企业的合规审查会是一个新变量。

按"先找瓶颈"来看,这篇其实指出了两个瓶颈。第一个是 token 单价,开源权重模型已经基本解决了这一层;第二个是解决了单价之后暴露出来的瓶颈:模型评估、路由、数据质量、GPU 利用率和重试失控。真正受益的是解决第二个瓶颈的那一层,而不是"又一个开源模型"。所以 AI板块 内部受益的层次会是:第一层仍然是算力,不管是前沿 API 还是企业自建开源模型,推理都要跑在 GPU 上,而英伟达通过收购 Hugging Face 同时控制了企业"评估、微调、量化、部署"开源模型的入口,这是它从卖芯片往上游渗透的一步;第二层是模型路由和推理聚合,OpenRouter 被 Stripe 以 75 亿美元收购本身就是对这一层价值的定价,Vercel 这类网关、Runware 这类推理平台也在这一层;第三层是企业私有化部署的整机和平台,Dell、Nutanix、HPE、Supermicro 在这里受益,但前提是 GPU 利用率能做上去,5% 的平均利用率提醒我们自建很容易变成闲置资产;第四层是评估、可观测性和 FinOps 工具,这是文章反复强调却还没有明显龙头的一层。承压的是前沿实验室的企业 API 定价权,不过文章所有受访者都认为它们不会被取代,复杂推理仍然是前沿模型的地盘。

edge AI板块 我也挂上,但权重低一些:文章提到小模型、蒸馏和"边缘容器"部署来降低延迟,这和终端设备上跑小模型是同一条技术路线,小模型能力接近大模型会直接扩大边缘推理的可用场景;不过原文主要讨论的还是企业机房,不是手机或机器人这类终端。

现在开源权重的流量占比还是来自 Vercel 和 OpenRouter 这类网关的观测,不一定代表大企业内部的真实结构,企业案例也大多是成本最敏感的公司。值得跟踪的是,前沿实验室下一轮企业定价是否明显下调,以及 AT&T 这样的公司最终能否把开源占比真的推到 70%——如果能,说明分层路由已经从实验变成默认架构。
