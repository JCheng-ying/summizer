# More banks say customers using AI agents are on their own — even if they get hacked
https://techcrunch.com/2026/11/18/more-banks-says-customers-using-ai-agents-are-on-their-own-even-if-they-get-hacked/

这篇文章背后的命题是:AI Agent 想进入高价值服务行业时,真正的阻力可能不是技术能力,而是责任归属和渠道控制权。Agent 能分析消费、给建议、甚至代为付款,但只要出了错由谁来赔这个问题没有答案,服务提供方就会用合同条款把 Agent 挡在门外——而这道门恰好也保护了它们自己的利润。

文章指出,美国第三大商业银行 Citibank 本周修改了服务条款,告诉使用第三方 AI 工具管理个人财务的客户:出了任何问题都是客户自己的事,即便是被黑客攻击。Citi 发言人对 TechCrunch 的说法是,随着第三方 AI 工具普及,银行希望客户理解共享银行登录凭证或授权这些工具访问账户的风险,因此更新了在线用户协议,明确选择授权第三方 AI Agent 访问账户的客户要为通过这些 Agent 进行的活动负责。文章提到,美国最大的两家银行 JPMorgan 和 Bank of America 上个月就宣布了类似政策,PNC 今天也改了条款;Citizens 本周给客户发邮件,同样警告客户要为 AI 助手的行为负责。Citi 的条款还更进一步:如果 AI 工具泄露了客户凭证或者被黑,黑客用账户做的任何事也由客户承担。

文章把银行的动机拆成两层。第一是安全,银行不愿意让不可靠的 AI 主体进入自己的系统,也不愿意为 Agent 有意或无意发起的交易做冲正。第二是竞争,AI 工具如果让消费者更容易避开不必要的手续费、把钱从低利率存款账户里挪走,就直接侵蚀银行利润,文章提到市场此前曾因为这种前景短暂波动;如果 Agent 成为人们做财务决策的重要入口,银行会争夺这条通道的控制权。这一点在条款里看得很清楚:Citi 写明客户使用银行自己提供的 AI Agent 不会承担额外责任。文章还举了 Anthropic 的做法作对照,它本月初推出的个人财务工具明确定位为"只读",不能移动、管理或投资用户的钱。文章最后把这放在一个更大的趋势里:AI 实验室承诺 Agent 会彻底改变人们和各种服务商打交道的方式,服务商的反应是"等一下",从网约车到餐饮都出现过。

这篇和 [ChatGPT Wallet 让 AI Agent 替你结账](2026-11-13-chatgpt-s-new-wallet-lets-ai-agents-shop-and-check-out-for-you.md) 正好形成对照:那篇里 OpenAI 用支付令牌化、结账前生物识别确认、保留卡组织争议机制来解决信任问题,还提到 Amazon 在阻止 AI Agent 访问网站;这篇则是银行直接用条款把风险推回给用户。再加上 [加州总检察长起诉 OpenAI Agent 失控事件](2026-11-16-california-state-ag-sues-openai-over-rogue-agent-incidents.md),Agent 的责任问题这一周已经同时出现在监管诉讼、支付产品设计和银行合同三个层面上。

个人看法:Agent 进入金融这类高价值服务,目前来看有三种路径:1. 拿用户的账号密码直接登录(screen scraping 式),这就是银行现在明确拒绝承担责任的模式,也是最容易出安全事故的模式;2. 通过受控的授权接口和令牌化,把 Agent 能做的事限定在额度、品类、时间边界内,ChatGPT Wallet 走的是这条;3. 服务商自己做 Agent,把入口留在自己手里,Citi 条款里的"自家 Agent 不追加责任"就是在为这条路铺垫。这三条路里,第一条在银行条款收紧之后会越来越难走,真正能规模化的是第二、三条。

先找瓶颈:Agent 在金融场景里卡住的不是模型能力,而是"授权与责任基础设施"——谁来证明这笔交易是用户真正授权的、凭证怎么不落到 Agent 手里、出了事怎么追溯。按这个逻辑,受益的层次会是:第一层是身份认证与授权基础设施,包括 Okta 这类身份管理公司,以及 Visa、Mastercard 的网络令牌化体系,它们恰好在解决"不给 Agent 真实凭证"这个问题;第二层是 Agent 治理和运行时监督工具,也就是前几篇写到的 Agent 治理/监督类初创公司所在的那一层;第三层是拥有客户关系的大银行本身,短期看它们用条款守住了渠道,自建 Agent 的能力反而成了护城河。对 AI 板块来说,这是一个偏利空的信号——消费级 Agent 在金融这个最诱人的变现场景里遇到了制度性阻力,"Agent 替代中间商"的叙事至少要打折扣;但它不影响底层算力的需求,只是把 Agent 的商业化价值从独立 AI 应用往现有平台和基础设施那一层转移。

现在还早,条款层面的表态更像是谈判的开局而不是终局。值得关注的是监管机构会不会出面规定 Agent 访问银行账户的标准接口和责任划分,以及有没有大银行开始和某个 AI 实验室签授权接入协议——那会是这条通道真正打开的信号。
