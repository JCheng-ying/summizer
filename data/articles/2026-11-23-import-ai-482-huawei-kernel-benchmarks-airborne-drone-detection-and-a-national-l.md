# Import AI 482: Huawei kernel benchmarks; airborne drone detection; and a national lab's AI science benchmark
https://importai.substack.com/p/import-ai-482-huawei-kernel-benchmarks

这一期 Import AI 看起来是四条互不相关的研究,但其中有一条线索贯穿始终:AI 正在被用来优化"AI 自身赖以运行的那一层"——芯片内核、科学实验、模型训练方式。如果 AI 能可靠地替人写出更快的硬件内核,那么在出口管制之下,算力差距就不再只由芯片制程决定,软件层的追赶速度会变成一个新的变量。

文章首先介绍了深圳河套学院(Shenzhen Loop Area Institute)发布的 AscendGYM,一个专门针对华为昇腾 NPU 的内核优化基准。文章指出,出口管制让中国机构拿不到最前沿的西方芯片、只能转向华为,所以让 AI 帮忙给昇腾写定制内核就格外重要。AscendGYM 要回答的问题是:给定一个正确的内核实现,agent 能否在可接受的预算内,在保持正确性的前提下进一步提升目标负载的性能;它从三个维度评估:第一是跨部署场景的适用性,第二是针对特定形状和场景的最佳性能,第三是获得这些提升所需的优化成本。配套的 AscendForge 环境提供编译、正确性检查、性能测量和反馈的统一接口。测试结果里单模型最好的是 Opus 5,其次是 GPT-5.6,再次是 GLM-5.3;在 Claude Code、Codex、OpenCode 三个框架里,Claude Code 的绝对分数最高,GLM 在其中表现也不错,而 GPT 在 Codex 里表现更好;Opus 5 更耗 token,GPT-5.6 更省 token。作者认为,这类软件是中国实现递归自我改进(RSI)的必要原料,同时也会影响出口管制的效果,因为它提供了一条提升国产芯片性能、缩小与西方差距的路径。

第二条是劳伦斯利弗莫尔国家实验室的 SciResearch-Eval。文章指出,它测的是 AI 科学家能不能诚实地表达不确定性:agent 拿到一块未知材料、一个热传导模拟器和一次加热实验,再自己设计四次实验,最终报告导热系数、热容和背面传热系数的 95% 置信区间。关键在于模拟器可能是故意做坏的——分辨率不足,或者漏掉了真实样品里的物理(随温度变化的导热率、胶接层、前表面辐射、侧面散热)。结果是,当模拟器缺少真实物理时,只有 GPT-6 Astra 和 Claude Fable 5.2 在默认设置下可靠,Claude 5.5 系列只有在最高推理档位才能恢复,更老的模型和开源权重模型完全做不到。这些强模型的做法是主动测量模拟器在哪里准、在哪里不准,再据此给出估计。

第三条是斯坦福教授 Yejin Choi 和 Carlos Guestrin 创办的 Noeri,融资 1.1 亿美元,主张由许多依赖各组织私有数据的小型专用模型来定义前沿,而不是一个单一的巨型模型;技术路线包括测试时训练、自蒸馏和"一个小模型指挥一组模型和工具"的 agent 编排。这家公司之前在 [Noeri 融资那篇](2026-11-16-noeri-raises-110m-to-help-companies-build-living-ai-systems-that-self-improve-ov.md) 里已经写过,这里不再展开。第四条是南京航空航天大学和香港科技大学发布的 A2A-UAV 空对空无人机检测数据集:105,263 个样本,分布在操场、公园、花园三个地点并且昼夜各半,每个样本包含 RGB 图、全景图、热成像、射频时频图、毫米波雷达点云和元数据,目标是 13 款商用机型共 15 架无人机,总量约 2.5TB。作者认为这类数据集是让 AI 操作机器人和无人机的原料,也有明显的军民两用属性,但他推测它对军队的意义,远不如乌克兰战场上可能正在积累的那类数据。

个人看法:这四条里我觉得最值得投资角度关注的是 AscendGYM。它和 [昇腾芯片数据中心在中国上线](2026-11-19-data-center-powered-by-huawei-ascend-chips-launches-in-china.md)、以及 [Luminal 挑战 CUDA 护城河](2026-11-12-with-23m-in-funding-luminal-is-the-latest-startup-to-put-nvidia-s-cuda-moat-in-i.md) 是同一条线索:英伟达真正的护城河从来不只是硬件,而是 CUDA 生态里十几年积累下来的高度优化的内核库。国产芯片最大的瓶颈之一就是这层软件——硬件参数可以追,但每一个算子、每一种张量形状都需要工程师手工调优,这需要大量时间和人。如果 AI agent 能把这部分工作自动化,那么追赶速度就从"招多少内核工程师"变成"有多少算力和多好的模型"。讽刺的是,测试里表现最好的恰恰是美国的模型,这说明在 [出口管制收紧那篇](2026-11-16-us-tightens-ai-chip-export-controls-to-deter-chinese-companies-from-accessing-co.md) 里讨论的硬件管制之外,前沿模型本身的可获取性也会变成管制要面对的新问题。

先找瓶颈,再找解决瓶颈的那一层。对 AI板块 来说,我会分三层看:第一层是华为昇腾生态本身,AscendGYM 直接降低的是"软件适配"这个瓶颈,受益的是华为和以昇腾为基础的国内算力服务商,但这一层对海外投资者基本不可投;第二层是能做内核优化的前沿模型和 coding agent 框架,Anthropic、OpenAI 以及智谱这类模型厂商——结合 SciResearch-Eval 的结果,能做"自主科学判断"的只剩最前沿的一两个模型,说明 AI for Science 这类高价值任务的收入会高度集中在头部;第三层仍然是算力基础设施,内核自动优化本身就要反复编译、跑基准,是一种额外的推理负载。对 edge AI板块,A2A-UAV 这类多模态空对空数据集针对的是无人机机载感知,瓶颈在于端侧要同时融合视觉、热成像、射频和雷达,利好的是能做低功耗多传感器融合的端侧芯片和模组,但目前这只是一个学术数据集,离商业化还很远。

这一期整体偏研究,短期不构成交易信号。值得关注的是 AscendGYM 之后会不会出现"AI 优化后的昇腾内核在真实训练任务上缩小了多少差距"的公开数据——如果有,那会是比任何芯片参数都更能说明国产替代进度的信号。
